# 🎮 Endless Learning Adventure

Game endless runner edukatif yang menggabungkan tantangan platformer, matematika, dan pemecahan masalah logis.

## 📖 Tentang Proyek

**Endless Learning Adventure** adalah prototipe game edukasi yang dirancang untuk membuat proses belajar menjadi lebih interaktif melalui permainan.

Pemain akan mengendalikan karakter untuk melewati berbagai rintangan, menyelesaikan tantangan matematika, dan menggunakan kemampuan berpikir logis untuk bertahan dalam permainan.

Proyek ini masih berada dalam tahap demo dan terus dikembangkan, terutama pada mekanik permainan, desain visual, animasi, serta tantangan pembelajaran interaktif.

## ✨ Fitur

- **Endless Gameplay:** Pemain menghadapi berbagai rintangan dalam perjalanan yang terus berlanjut.
- **Tantangan Matematika:** Selesaikan soal matematika untuk melewati rintangan tertentu.
- **Jembatan Interaktif:** Gunakan konsep matematika, seperti Kelipatan Persekutuan Terkecil (KPK), untuk menentukan kapan jembatan dapat muncul.
- **Kontrol Keyboard:** Kendalikan karakter menggunakan keyboard.
- **Sistem Nyawa:** Hindari kesalahan dan bertahanlah melewati berbagai tantangan.

*Fitur dan mekanik permainan dapat berubah selama proses pengembangan.*

## 🛠️ Teknologi dan Pengembangan

Versi saat ini merupakan demo berbasis web yang digunakan untuk menguji mekanik permainan, desain level, dan interaksi pemain.

Ke depannya, proyek ini direncanakan untuk dikembangkan lebih lanjut menggunakan **Godot Engine dan GDScript**.
